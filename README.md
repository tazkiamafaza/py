# Mini Project Pemrograman Komputer: Sistem Analisis Kualitas Udara

Proyek ini merupakan program berbasis **Python** yang dirancang untuk memantau, mengelola, dan menganalisis data tingkat kualitas udara serta kondisi lingkungan secara terstruktur.

## Fitur Utama
* **Pemantauan & Evaluasi Data:** Membaca dan memproses parameter kualitas udara untuk mengevaluasi tingkat polusi lingkungan.
* **Struktur Program Terorganisir:** Menggunakan fungsi modular dan alur logika yang rapi sehingga mudah dijalankan dan dikembangkan.
* **Output Informatif:** Menampilkan hasil analisis dan kategori status kualitas udara secara jelas di terminal.

## Cara Menjalankan Program
1. Pastikan **Python 3** sudah terinstal di komputer Anda.
2. Unduh file `CODINGAN MINI PROJECT (2).py` dari repository ini (atau klik **Code -> Download ZIP**).
3. Buka terminal atau editor kode (seperti VS Code) di folder tempat file tersimpan.
4. Jalankan perintah berikut:
   ```bash
   python "CODINGAN MINI PROJECT (2).py"
   ```
